<ul>
                                <li> Developed a Naive Bayes model from scratch to classify the political spectrum of news article headlines,
                                using scraped data from five major news outlets using BeautifulSoup and the sitemap.xml of each outlet.</li>
                                <li> Implemented a term frequency-inverse document frequency matrix as a feature input to minimize the influence of low-impact tokens that were tokenized using spaces.</li>
                            </ul>
